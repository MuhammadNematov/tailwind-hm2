# Hair Salon Website

Современный адаптивный сайт парикмахерской, созданный по макету Figma с использованием Tailwind CSS.

## About Project

Этот проект был разработан с использованием:

- HTML5
- Tailwind CSS
- Vite
- JavaScript

Сайт полностью адаптивный и создан по подходу Mobile First.

## Installation

Clone repository:

```bash
git clone https://github.com/your-username/project-name.git
```

Go to project folder:

```bash
cd project-name
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm run dev
```
